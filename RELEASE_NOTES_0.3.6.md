# Domain Admin Console v0.3.6

Автор разработки: **BasiliyWolf**

## Изменения интерфейса

- приложение запускается сразу развёрнутым на весь экран;
- основное меню всегда находится в самой верхней строке;
- вкладки всех административных модулей возвращены и остаются видимыми;
- при большом количестве вкладок используется несколько строк;
- экран загрузки больше не закрывает заголовки вкладок;
- добавлена собственная иконка Domain Admin Console;
- добавлено окно `О программе`.

## Проверка обновлений

Вариант реализации — **GitHub Releases API**:

- при запуске выполняется фоновый запрос последнего опубликованного Release;
- текущая версия сборки сравнивается с `tag_name` GitHub Release;
- если версия новее, пользователь получает предложение открыть страницу релиза;
- ручная проверка доступна через `Справка → Проверить обновления`;
- окно `О программе` также содержит кнопку проверки;
- ошибки сети при автоматической проверке не мешают запуску приложения.

Настройка репозитория находится в `Services/GitHubUpdateService.cs`:

```csharp
public const string RepositoryOwner = "BasiliyWolf";
public const string RepositoryName = "DomainAdminConsole";
```

Текущий URL проверки:

```text
https://api.github.com/repos/BasiliyWolf/DomainAdminConsole/releases/latest
```

Автоматическое скачивание/замена EXE в этой версии не выполняется. Для административного ПО безопаснее сначала открывать официальную страницу Release; полноценный self-updater можно добавить отдельным подписанным updater-процессом в следующей версии.
