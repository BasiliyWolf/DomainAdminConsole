# Domain Admin Console 0.3.8

## Исправления

- Исправлена ошибка `System.Text.Json`: `'E' is an invalid start of a value`.
  - ошибки удалённых PowerShell-команд больше не передаются напрямую в JSON parser;
  - вместо непонятного исключения отображается реальная ошибка PowerShell/WinRM;
  - добавлена проверка корректности JSON перед десериализацией.
- Удалено большое изображение из окна **«О программе»**.
- Окно **«О программе»** сделано компактнее и оставляет только информацию о версии, авторе, GitHub и обновлениях.
- Заменена иконка приложения на нейтральную системно-административную: монитор/консоль + защитный щит.
- Версия приложения обновлена до **0.3.8**.
