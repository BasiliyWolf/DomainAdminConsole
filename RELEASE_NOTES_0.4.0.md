# Domain Admin Console 0.4.0

## UI / UX

- Полностью переработана строка вкладок: непрерывная лента с пиксельной прокруткой и фиксированными кнопками ◀ / ▶ по краям.
- Убраны пустые области между последней видимой вкладкой и правой кнопкой прокрутки.
- Унифицированы отступы кнопок и иконок: одинаковый padding, ImageBeforeText и стабильное центрирование.
- Вкладка «Утилиты» переделана в компактные логические группы без огромных растянутых плиток.

## Реестр

- Добавлено древовидное представление разделов реестра.
- Корни HKEY_LOCAL_MACHINE, HKEY_CURRENT_USER, HKEY_CLASSES_ROOT, HKEY_USERS и HKEY_CURRENT_CONFIG.
- Подразделы загружаются лениво при раскрытии узла.
- Справа отображаются значения выбранного ключа.
- Контекстное меню дерева: обновить ветку и копировать путь.
- Создание раздела теперь запрашивает имя дочернего ключа.

## Файловый менеджер

- Двухпанельный файловый менеджер сохранён и дополнен деревом каталогов в каждой панели.
- Локальное дерево строится по доступным дискам.
- Удалённое дерево получает диски и каталоги через WinRM.
- Деревья загружаются лениво и синхронизируются с путём панели.
- Панели команд переразмечены в компактные строки без переноса элементов.

## Журналы Windows

- Двойной клик по событию открывает отдельное окно подробностей.
- В окне отображаются дата/время, Event ID, источник, уровень и полное сообщение.
- Добавлена кнопка копирования события и пункт «Подробности события» в контекстном меню.
