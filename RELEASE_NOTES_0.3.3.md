# Domain Admin Console v0.3.3

Небольшое обновление представления списка компьютеров домена.

- В колонке состояния оставлена только цветная точка: зелёная — ONLINE, красная — OFFLINE, серая — проверка ещё выполняется.
- Ping, WinRM и SMB объединены в одну колонку `Ping / WinRM / SMB`; доступные проверки выводятся зелёным текстом через запятую.
- RDP отображается одной цветной точкой: зелёной при доступном RDP и красной при недоступном.
- Offline-компьютеры продолжают отображаться в списке.

Все исправления v0.3.2 и WinRM hotfix сохранены.
