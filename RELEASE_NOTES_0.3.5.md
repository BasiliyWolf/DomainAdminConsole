# Domain Admin Console v0.3.5

UI hotfix и улучшение навигации.

## Исправлено

- Некорректные/«битые» иконки в кнопках и контекстных меню.
- Исчезновение заголовков вкладок после появления экрана загрузки.
- Z-order между рабочим `TabControl` и splash/loading overlay.

## Добавлено

- Верхнее меню `Подключение / Домен / Разделы / Вид`.
- Полная навигация ко всем вкладкам через `Разделы`.
- Группы: `Основное`, `Мониторинг`, `Домен`, `Администрирование`, `Инструменты`.
- Быстрые команды RDP, C$, обновления текущего ПК и сканирования домена.
- Отметка выбранной вкладки в выпадающем меню.
- Команды `Следующая вкладка` и `Предыдущая вкладка` в меню `Вид`.

## Иконки

Иконки получаются из системной оболочки Windows через `SHGetStockIconInfo` (`shell32.dll`), поэтому отдельные графические ресурсы или файлы иконок проекту не нужны.
