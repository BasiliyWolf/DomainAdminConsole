# Domain Admin Console 0.3.9

## UI / UX

- Переработана навигация по вкладкам: заголовки всегда в одну строку, кнопки прокрутки находятся строго слева и справа от строки вкладок и больше не занимают вертикальные полосы по краям рабочей области.
- Удалена верхняя панель прямого подключения. Прямое подключение по DNS/IP перенесено в меню **Подключение → Подключиться по имени / IP...** (`Ctrl+L`). Основной сценарий — выбор ПК из доменного списка.
- Фильтр **Только активные** перенесён под список компьютеров.
- Нормализованы отступы, размеры кнопок и положение элементов ввода в панелях инструментов.
- Иконки кнопок теперь фиксированы по левому краю и не смещают текст при разных размерах кнопок.
- Полностью переработана вкладка **Утилиты**: команды сгруппированы в логические блоки «Подключение и оснастки», «Система», «Сеть», «Сообщение активному пользователю».
- Переработаны **Массовые действия**: выбор целей и параметры выполнения разнесены на две стабильные строки без переносов.
- Переработан **Wake-on-LAN**: убраны пустые отступы, подсказка вынесена в отдельную компактную строку.
- Вкладка **Обзор** получила карточки с ПК, пользователем, ОС, IPv4 и временем работы, отдельный блок дисков и системной информации.

## Совместимость

- Все функции v0.3.8 сохранены, включая автоматическое обновление через GitHub Releases, WinRM hotfix, корректный JSON parsing и исправления кодировки.
