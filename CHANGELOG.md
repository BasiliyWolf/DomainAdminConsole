# Changelog

## 0.4.1

- Кнопки интерфейса переведены в адаптивный режим: если текст не помещается, отображается только иконка, а полное действие показывается в Tooltip.
- Добавлен стабильный отступ между иконкой и текстом кнопки.
- Контекстные меню сохраняют полные названия действий даже для кнопок, отображаемых только иконкой.
- В журнале Windows добавлена цветовая кодировка уровней Critical / Error / Warning / Information / Verbose.
- Уровень события определяется по числовому `Level`, поэтому цветовая схема не зависит от языка Windows.

## 0.4.0

- Новый scrollable tab strip без пустых зон.
- Единые отступы иконок и текста на кнопках.
- Древовидный удалённый реестр.
- Деревья каталогов в двухпанельном файловом менеджере.
- Компактная переработка вкладки «Утилиты».
- Подробное окно события по двойному клику в Windows Event Log.

## 0.3.9

- Single-line custom tab navigation with left/right scrolling.
- Direct connect moved to the application menu.
- Overview, Utilities, Bulk Actions and Wake-on-LAN UI cleanup.
- Consistent toolbar/input spacing and stable button icon alignment.
- "Only active" filter moved below the domain computer list.

# Changelog

## 0.3.8

- Полностью заменён механизм иконок: вместо `SHGetStockIconInfo` используются собственные DPI-safe GDI+ иконки для кнопок и контекстных меню.
- Верхний MenuStrip использует стандартные текстовые пункты без проблемных изображений.
- Репозиторий обновления установлен на `https://github.com/BasiliyWolf/DomainAdminConsole`.
- Добавлен диалог новой версии с кнопкой `Обновить сейчас`.
- Добавлена автоматическая загрузка ZIP/EXE из GitHub Release, подготовка updater-скрипта, замена файлов после завершения приложения и автоматический перезапуск.
- GitHub Actions формирует `DomainAdminConsole-win-x64.zip` и публикует его в Release при push тега `v*`.

## 0.3.1

- Исправлена Windows-аутентификация WinRM при работе от текущей доменной учётной записи: используется `NegotiateWithImplicitCredential`.
- Удалён внутренний `CancelAfter`, который мог порождать `OperationCanceledException` при переключении между HTTP/5985 и HTTPS/5986.
- Перед созданием Runspace проверяется доступность WinRM TCP endpoint; недоступный HTTPS больше не задерживает подключение.
- Увеличен безопасный OpenTimeout для коротких доменных WinRM-запросов.
- Сообщения WinRM теперь содержат ошибку конкретного endpoint и вложенные причины.
- Сохранён hotfix безопасной инициализации `SplitContainer`.

## 0.3.0

- Добавлена вкладка массовых действий по активным ПК, всем ПК AD или группе избранного.
- Добавлена очередь результатов массовых операций и ограничение параллелизма.
- Добавлен двухпанельный файловый менеджер локальный ПК ↔ удалённый ПК.

- Добавлен модуль BitLocker / TPM; доступны статус, Suspend на одну перезагрузку и Resume.

- Добавлены Device Manager / драйверы: PnP-устройства, версии драйверов, enable/disable и `pnputil /scan-devices`.

- Сохранённый скрипт можно запустить на текущем ПК или передать в массовые действия.
- Audit log расширен на новые административные операции.
