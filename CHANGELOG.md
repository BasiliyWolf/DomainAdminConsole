# Changelog

## 0.3.0

- Добавлена вкладка массовых действий по активным ПК, всем ПК AD или группе избранного.
- Добавлена очередь результатов массовых операций и ограничение параллелизма.
- Добавлен двухпанельный файловый менеджер локальный ПК ↔ удалённый ПК.
- Добавлены копирование каталогов, создание, переименование и удаление файлов/папок.
- Добавлен Wake-on-LAN с локальной базой известных MAC-адресов.
- Добавлен модуль BitLocker / TPM; доступны статус, Suspend на одну перезагрузку и Resume.
- Добавлены принтеры, очередь печати, отмена задания и Restart Spooler.
- Добавлен просмотр LocalMachine certificates и экспорт публичной части `.cer`.
- Добавлено управление Windows Firewall: профили, правила, enable/disable, создание Inbound Allow и удаление правил.
- Добавлены SMB Sessions и SMB Open Files с подтверждаемым принудительным закрытием.
- Добавлены Device Manager / драйверы: PnP-устройства, версии драйверов, enable/disable и `pnputil /scan-devices`.
- Добавлена локальная библиотека сохранённых PowerShell-скриптов с категориями и описанием.
- Сохранённый скрипт можно запустить на текущем ПК или передать в массовые действия.
- Audit log расширен на новые административные операции.
- Версия приложения/файла повышена до 0.3.0.

## 0.2.0

- Добавлены избранные компьютеры, группы и tray-подменю.
- Добавлен RDP Shadow через Windows Terminal Services API.
- Добавлен удалённый редактор реестра.
- Добавлено управление Scheduled Tasks.
- Добавлен список установленных x64/x86 программ и удаление MSI по ProductCode.
- Добавлено управление локальными пользователями и локальной группой Administrators по SID.
- Добавлены сетевые интерфейсы и IPv4-маршруты.
- Добавлена диагностика Windows Update, pending updates, StartScan и StartInstall.
- Добавлен локальный audit-log JSONL.
- При доменном сканировании WinRM-доступных машин определяется текущий пользователь/сеансы для быстрого фильтра.
- WinRM-клиент пробует HTTP/5985 и HTTPS/5986.
- Добавлено контекстное меню компьютеров Active Directory.
- Манифест приложения изменён на `requireAdministrator`.

## 0.1.0

- Первый рабочий каркас.
- Active Directory inventory и проверка online.
- PowerShell Remoting.
- Диски, процессы, службы, Event Logs, порты.
- Ping / tracert.
- Поиск пользователь → ПК по всему домену.
- ПК → пользователи.
- Базовые административные утилиты и tray.
