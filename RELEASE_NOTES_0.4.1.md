# Domain Admin Console 0.4.1

## UI
- Адаптивные кнопки: при нехватке ширины остаётся только иконка.
- Полное название скрытой команды доступно через Tooltip при наведении.
- Добавлен одинаковый визуальный промежуток между иконкой и текстом.

## Журналы Windows
- Цветовая кодировка событий по уровню:
  - Critical — насыщенный красный;
  - Error — светло-красный;
  - Warning — жёлтый;
  - Information — светло-синий;
  - Verbose — серый.
- Классификация основана на числовом Event Level и не зависит от локализации Windows.
