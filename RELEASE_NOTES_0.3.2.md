# Domain Admin Console v0.3.2

Технический hotfix интерфейса, доменного списка и удалённого вывода поверх v0.3.1.

## Исправлено

- ошибки JSON-десериализации `DateTime` в файловом менеджере и сертификатах;
- кодировка `systeminfo`, `ipconfig`, `ping`, `tracert`, `gpresult`, `driverquery`, `quser` и других native Windows-команд;
- кнопка `Системная информация`;
- отправка сообщения пользователям: WTS API + fallback `msg.exe` через WinRM;
- дублирование пользователя в формате `DOMAIN\user, user`;
- очистка данных предыдущего компьютера при переподключении/обновлении.

## Интерфейс

- сортировка по клику на заголовок во всех таблицах;
- таблицы растягиваются по ширине;
- единое контекстное меню таблиц;
- автоматическое обновление вкладок при переходе;
- ProgressBar проверки доменных ПК;
- online/offline ПК отображаются одновременно;
- offline отмечается красным, online зелёным;
- Ping / WinRM / SMB / RDP теперь текстовые цветные индикаторы вместо checkbox;
- в таблице портов выводится описание известных служб.

## Сохранено

- WinRM hotfix v0.3.1 (`NegotiateWithImplicitCredential`, HTTP/HTTPS endpoint probing);
- SplitContainer hotfix;
- весь функционал v0.3.0.
