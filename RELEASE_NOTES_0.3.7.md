# Domain Admin Console v0.3.7

Автор разработки: **BasiliyWolf**

## Интерфейс

- вкладки снова расположены в одной строке;
- добавлены кнопки навигации `◀` и `▶` слева и справа от строки вкладок;
- исправлены повреждённые иконки: новый набор рисуется приложением самостоятельно и корректно работает при масштабировании Windows;
- `Избранное` перенесено в верхнее меню и больше не занимает отдельную вкладку.

## Избранное

Через пункт `Избранное` доступны:

- добавление текущего подключённого ПК;
- добавление выбранного компьютера из списка домена;
- группировка записей;
- подключение;
- RDP;
- открытие `C$`;
- изменение и удаление записи.

## Обновление через GitHub

Репозиторий:

`https://github.com/BasiliyWolf/DomainAdminConsole`

При обнаружении новой версии приложение предлагает:

- **Обновить сейчас**;
- открыть страницу GitHub Release;
- отложить обновление.

Для автоматической установки Release должен содержать asset `DomainAdminConsole-win-x64.zip` (предпочтительный вариант). Поддерживается также подходящий `DomainAdminConsole*.zip` или `.exe`.

GitHub Actions автоматически создаёт ZIP после publish. При теге `v*` workflow создаёт либо обновляет Release и загружает asset.
